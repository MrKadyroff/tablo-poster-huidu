# Режим «Аэропорт» — двустороннее табло

Один макет курсов выводится на обе стороны двустороннего вертикального табло Huidu A3L
(каждая сторона 192×256). Режим включается флажком, у него свои настройки, обычные точки он не затрагивает.

## Как это работает

Курсы → макет одной стороны (холст 192×256) → склейка по настройкам → файл в папке вывода → отправка на контроллер.

| `joinLayout` | Что происходит | Размер для контроллера |
|---|---|---|
| `horizontal` | каждая сторона поворачивается на `sideRotation` (90/270° по часовой), стороны клеятся слева и справа | 512×192 |
| `vertical` | без поворота, сторона A сверху, B снизу (экран повёрнут в HDPlayer) | 192×512 |

Сторона B преобразуется по `secondSide`: `same`, `mirror` (зеркало по горизонтали), `rotate180`, `flipVertical`.
JPEG и GIF поддерживаются; GIF клеится покадрово, задержки кадров и число повторов сохраняются.

## Конфигурация

`layout/points/<id>.compose.json`:

```json
{
  "canvas": { "width": 192, "height": 256 },
  "doubleSided": { "enabled": true, "joinLayout": "horizontal", "sideRotation": 270, "secondSide": "mirror" }
}
```

| Поле | Значения | По умолчанию |
|---|---|---|
| `enabled` | true / false | false |
| `joinLayout` | `horizontal`, `vertical` | `horizontal` |
| `sideRotation` | 90, 270 (только для `horizontal`) | 270 |
| `secondSide` | `same`, `mirror`, `rotate180`, `flipVertical` | `mirror` |

В `config/points/<id>.json` `HuiduLed.ScreenWidth/ScreenHeight` равны размеру склейки — окно настроек ставит их само.

## Окно настроек → «Размер табло» → «Аэропорт — двустороннее табло»

Флажок, списки (склейка, поворот, вторая сторона), подпись «На контроллер уйдёт: W×H»,
«Показать тест» (предпросмотр) и «Отправить тест на табло» (временно заменяет курс до следующего обновления).
Превью на вкладке «Дизайн» всегда показывает макет одной стороны.

## Подбор настроек (один раз, по тестовой картинке)

1. Включить режим, выбрать склейку по схеме HDPlayer (512×192 без поворота или 192×512 с поворотом).
2. Отправить тест. Картинка лежит на боку не в ту сторону — сменить поворот 270° ↔ 90°.
3. На стороне B текст задом наперёд — «Зеркально»; вверх ногами — «Вверх ногами»; зеркало по вертикали — «Зеркально по вертикали».
4. Стороны поменялись местами — проверить порядок карт в цепочке HDSet.

Тест: рамка по краю, крупная «R» и зелёная стрелка вправо под ней.

## Что не менять

Размер экрана и порядок карт в HDSet; настройки обычных точек. Поворот делайте либо в HDPlayer, либо в программе — не в обоих местах.
